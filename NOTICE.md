# Notice / 说明

This repository is a tutorial-style engineering archive for a Unitree Go2 navigation prototype.

本仓库是 Unitree Go2 导航原型的教程式工程归档。

The project uses ROS2, Nav2, AMCL, and Unitree-related software interfaces. Their respective licenses and attribution requirements should be followed.

项目使用 ROS2、Nav2、AMCL 和 Unitree 相关软件接口，应遵守各自许可证和引用要求。

Copied third-party voice source code is not included in the public release unless its reuse permissions are confirmed.

在复用许可得到确认前，公开版本不包含复制的第三方语音源码。
