# Third-party components and references

This project is built with and documents the use of several
third-party open-source technologies, including:

- ROS 2 Foxy
- CycloneDDS and `rmw_cyclonedds_cpp`
- Unitree ROS 2 messages and APIs
- `slam_toolbox`
- `robot_localization`
- Navigation2 / Nav2
- ROS TF and point-cloud processing components

Selected Go2-specific implementation details were studied and adapted
with reference to:

- `rbgyhjn/go2-nav2-amcl`
  - pinned reference commit:
    `8a022d5ca389af2a9b793849e28956992f6a52a5`

The voice-interaction design connects with work from the collaborator
repository:

- `PYH1107/go2-hci`
  - pinned reference commit:
    `77520f4d3fda1f46ddc71355a76bf66ac56fc6b9`

This repository does not relicense the third-party projects listed
above. Their source code, copyrights and licensing terms remain with
their respective authors and upstream repositories.

Short code excerpts may appear in the documentation for technical
explanation and attribution. Complete upstream implementations should
be obtained from their original repositories.
